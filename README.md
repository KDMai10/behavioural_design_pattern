# Behavioral Design Patterns in PHP

Laboratory Activity #4 - ITPE 130: Integrative Programming 2

Plain PHP (8.0+), no frameworks. Each folder has the source files, an `index.php` demo, and a sample `output.txt`.

| # | Folder | Pattern | Application |
|---|--------|---------|-------------|
| 1 | 01-chain-of-responsibility | Chain of Responsibility | Student Request Processing |
| 2 | 02-command | Command | Student Action/Command System (with Undo) |
| 3 | 03-interpreter | Interpreter | Student Search/Query System |
| 4 | 04-iterator | Iterator | Student Record Collection |
| 5 | 05-mediator | Mediator | Student Communication System |
| 6 | 06-memento | Memento | Student Profile Undo System |
| 7 | 07-observer | Observer | Grade Notification System |
| 8 | 08-state | State | Student Enrollment Status |
| 9 | 09-strategy | Strategy | Grade Calculation System |
| 10 | 10-template-method | Template Method | Student Report Generation |
| 11 | 11-visitor | Visitor | Student Record Operations |

## How to run

```
cd 09-strategy
php index.php
```

Run everything at once: `php run-all.php`
